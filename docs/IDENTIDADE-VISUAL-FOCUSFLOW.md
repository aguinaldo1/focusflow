# FocusFlow — Identidade Visual

## Versão

Documento de identidade visual da versão 1.0 do FocusFlow.

A versão 1.0 não utiliza inteligência artificial.

A integração com IA fica planejada para uma futura versão 2.0.

---

# 1. Conceito

O FocusFlow possui como identidade um assistente robótico futurista em 3D.

O personagem deve transmitir:

- tecnologia;
- foco;
- produtividade;
- confiança;
- simpatia;
- assistência;
- progresso.

A aparência deve combinar com a interface HUD escura do aplicativo.

---

# 2. Mascote oficial

O mascote oficial do FocusFlow é um robô assistente 3D original.

Características principais:

- capacete tecnológico;
- visor preto brilhante;
- olhos luminosos em cyan;
- expressão amigável;
- estrutura metálica clara e grafite;
- iluminação cyan;
- pequenos detalhes em laranja;
- núcleo energético luminoso no peito.

O mascote deve possuir identidade própria e não reproduzir personagens existentes.

---

# 3. Papel do mascote na versão 1.0

Na versão 1.0, o mascote funciona como:

- identidade visual;
- assistente contextual;
- indicador complementar dos estados do Pomodoro;
- elemento de comunicação com o usuário.

Não haverá:

- LLM;
- chatbot;
- geração de texto;
- API de IA;
- tomada de decisões por IA.

As mensagens serão determinadas pelo estado da própria aplicação.

---

# 4. Direção visual

## Interface

Paleta principal:

- fundo: azul/preto profundo;
- cyan: tecnologia, foco e atividade;
- azul: elementos auxiliares;
- âmbar/laranja: atenção e pausa;
- verde: sucesso;
- vermelho: ações destrutivas.

## Princípio

A interface deve ser:

**futurista, tecnológica e limpa.**

O cronômetro continua sendo o elemento funcional principal.

O mascote deve apoiar a experiência e nunca competir visualmente com o Timer HUD.
