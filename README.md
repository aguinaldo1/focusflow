# FocusFlow

FocusFlow é um aplicativo desktop de Pomodoro adaptativo criado para
organizar sessões reais de estudo e trabalho.

## Problema

Pomodoros tradicionais controlam o tempo, mas não ajudam a estimar
quanto esforço um assunto necessita nem mantêm o contexto de múltiplos
objetivos de estudo.

## Proposta

O FocusFlow pretende combinar:

- sessões de foco;
- gerenciamento de até cinco objetivos;
- estimativa de complexidade;
- recomendação de quantidade de Pomodoros;
- histórico de sessões;
- interface desktop pequena e flutuante.

## Estado atual

Projeto em desenvolvimento.

Fase atual:

`Fase 0 — Fundação técnica`

## Stack inicial

Java 21 + Maven.

JavaFX e SQLite serão introduzidos apenas quando suas funcionalidades
forem necessárias.

## Princípio do projeto

O objetivo não é maximizar complexidade técnica.

O projeto deve demonstrar decisões, trade-offs, testes, documentação
e evolução a partir de uso real.
